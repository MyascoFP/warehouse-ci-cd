
# Warehouse CI/CD

Учебный проект для выполнения практической работы № 2
по настройке CI/CD.

## Функциональность

- Добавление материалов на склад
- Получение остатков материалов
- Списание материалов
- Проверка корректности операций
- Подсчет общего количества остатков

## Технологии

- Python
- Pytest
- Git
- GitHub Actions

## Запуск тестов

python -m pytest -v

## CI/CD

Учебный проект по изучении CI/CD с использованием GitHub Actions. Который реагирует на каждый коммит.
